# Appfigures API: Access, Limits, and Add-ons

The **Appfigures API** gives you programmatic access to tons of data—from app and store performance to metadata and more.

### The Basics

If you have an Appfigures account, you can start using the API for free to get data on the apps you’re already tracking. Everything you see in your Appfigures reports is _also_ available through the API.

### Daily Call Limits

By default, every account gets **1,000 API requests per day** for free. If you need more, you can easily **increase** your limit. Packages range from **2,500** to **50,000 requests per day.** Just head to **Manage** \> [API Access](https://appfigures.com/account/api) and pick the package that works best for you.

### Replying to Reviews

Want to reply to **App Store** or **Google Play** reviews programmatically? You’ll need an add-on that comes with the **Grow plan**.

### Additional Access

Some API features go beyond the free tier. Here’s what you should know:

### Public Data Access

The API lets you search and get data for **any app**, not just the ones you track. You can:

- Search apps by metadata
- View ratings and ranks
- See featured placements
- Read reviews, and more

Accessing data for apps you don’t track uses **credits**. Each request costs one or more credits, which you can buy in packages. If you run out, the API will tell you how many credits you need.

To purchase credits, you'll need **Grow** or above, and to enable the [Public Data API Add-on](https://appfigures.com/account/addons/public-data), and you can even set up automatic top-ups.

###### Public Data Credits Per Route:

1. **Product** metadata → **2**
2. **Extended** metadata → **5** credits (7 in total with Product metadata included)
3. **Ratings → 3**
4. **Featured** → **5**
5. **Reviews** → **3**
6. **Ranks** (single app) → **5**
7. **Ranks** (Top list) → **10**
8. **ASO** → 5 credits

### Data Processors & Resellers

You can use the API internally without restrictions. But if you want to **resell App Store data**, you’ll need a partnership agreement with Appfigures.
