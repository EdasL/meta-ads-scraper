# Field Desk — agent guide

## Product copy (voice)

ALL product copy is **plain, clear, professional**. Every user-facing UI
string — labels, buttons, headings, empty states, loading states, errors,
tooltips, emails, toasts — is short, scannable, and honest. No marketing
fluff ("leverage", "seamless", "unlock", "empower", "supercharge",
"delightful"…), no exclamation spam, no novelty voices.

UI elements must be grounded in real data (the ads, the store listings, the
DB). Do not add hardcoded or re-derived labels that restate an adjacent
number (e.g. trend words like "steady"/"rising" next to a growth percent).

Keep product nouns intact: **Field Desk**, **GemScore**, **cohort**.
